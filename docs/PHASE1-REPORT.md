## What was built

A production-ready Astro 5 + TypeScript (strict) + Tailwind CSS v3 foundation for the
Lottery Calculator platform, with the first fully functional calculator.

### Architecture

- `src/data/site.ts` — single central config: siteName, siteUrl, description, OG image.
  Every canonical, sitemap URL, and meta tag reads from here.
- `src/data/taxes/federal.ts` — 2025 IRS single-filer brackets, withholding rate,
  effective dates, source, notes. Single source of truth.
- `src/data/taxes/states.ts` — all 50 states + DC. Each rule carries
  `taxRate`, `withholdingRate`, `effectiveDate`, `expirationDate`, `source`, `notes`.
  Rates are **planning estimates** (top marginal 2025 rates, Tax Foundation-grounded);
  CA = $0 (lottery winnings exempt), no-income-tax states = $0.
- `src/lib/calculator/` — pure engine: `lottery.ts` (calculateLotteryWinnings,
  validateLotteryForm), `tax.ts` (bracket math, state tax), `formatting.ts`
  (Intl-based currency/percent/parse). Zero DOM access.
- `src/lib/seo/metadata.ts` — buildPageMeta, absoluteUrl, JSON-LD helpers
  (WebSite, BreadcrumbList, FAQPage). No hard-coded meta in templates.
- `src/components/` — Header (responsive + mobile menu), Footer, NumberInput,
  CurrencyInput, StateSelect, LotteryCalculator (interactive widget),
  ResultCard, FAQ (details/summary, zero JS), Breadcrumbs, Disclaimer, RelatedLinks.
- Client JS: **one 7.56 kB bundle** (3.08 kB gzipped) for the calculator, which
  imports the *same* engine the tests exercise — no duplicated formulas.
  One tiny inline script toggles the mobile menu.

### SEO foundation

Unique title/description/canonical per page, OG + Twitter cards, robots directives,
WebSite schema (home), BreadcrumbList schema (calculator page), FAQPage schema (home —
matches visible FAQ content), semantic headings, breadcrumbs, 404 with noindex.

### Honesty constraints honored

- Every figure labeled "Estimated"; disclaimer on every calculator surface.
- No guaranteed-accuracy / guaranteed-winnings / better-odds claims anywhere.
- No fake review/rating schema. FAQ schema only where visible Q&A exists.
- Future calculators (Tax, Payout, Annuity, Odds, Powerball, Mega Millions) render as
  non-clickable "Coming soon" cards — zero broken links. Nav lists only existing pages.

## Known limitations / honest gaps (by design for Phase 1)

1. Tax rates are 2025 planning estimates, not a live tax feed. The architecture
   (centralized config + effective/expiration dates + sources) exists precisely so a
   later phase can update them without touching components.
2. Federal estimate uses single-filer brackets on the full cash amount; ignores
   standard deduction, other income, filing status, credits. Stated on-page.
3. State estimate applies the top marginal rate flat; ignores brackets, local taxes
   (MD counties, NYC noted in data), deductions. Stated in data notes + on-page.
4. `siteUrl` is a placeholder (`https://lotterycalculator.example.com`) — one-line
   change in `src/data/site.ts` before launch.
5. OG image is a lightweight SVG placeholder.
